# 设计与迭代日志

五轮「实现 → 测试 → 批评 → 修改」的真实记录。测试手段：Vitest 单元测试 + 真实浏览器（IAB）行为断言（音频图增益/能量采样、计时器状态机、快捷键、持久化）+ 截图视觉评审。

## Round 1 — 脚手架 + 音频引擎核心 → 测试

**实现**：Vite + TS 工程、噪声缓冲工厂（白/粉/棕）、随机事件调度器、雨/火/风三通道、引擎主链（通道增益 → 主增益 → 压缩器 → 分析器）。

**测试发现**：
- ❌ **持续层噪声源从未调用 `.start()`**：引擎启动、状态全部正确，但分析器能量为 0。事件层走 `triggerVoice`（内部有 start）所以雨滴/爆裂正常，持续层全哑。
- ✅ 修复：六个通道全部补上 `source.start()`；回归验证雨声能量 68.85（宽频嘶声）、火 0.42（低频闷响，符合频谱预期）。

## Round 2 — 六通道 + 预设 → 测试

**实现**：溪流（水声 LFO + 气泡）、夜虫（鸣叫串）、鸟鸣（扫频啁啾）、四组声景预设、雷作为雨的伴生事件。

**测试发现**：
- ❌ **AudioContext 挂起时（自动播放策略未放行）时间自动化被冻结在 t=0**：期间调度的淡入淡出失效，恢复后增益瞬间跳变。在严格自动播放策略的浏览器中是必现 bug。
- ✅ 修复：`start()` 先尝试 resume 再建图；新增 `applyParam` 策略——running 时用 `setTargetAtTime`，suspended 时直接赋值，恢复后无跳变。

## Round 3 — 计时器 + 统计 + 持久化 → 测试

**实现**：FocusTimer 状态机（Date.now 锚定防后台漂移）、阶段切换风铃（上行/下行可盲辨）、统计（今日/连续/7 天迷你柱）、localStorage 持久化、快捷键（空格/M/T/1-6）。

**测试发现**：
- ❌ **`cancelAndHoldAtTime(now)` + 同时刻 `setTargetAtTime` 在 Chromium 中被持有事件吞掉**：预设切换后旧通道永不淡出（增益卡在持有值，能量 65.8 不衰减）。
- ✅ 修复：改为「`cancelScheduledValues` + `setValueAtTime(当前值)` 锚定 + `setTargetAtTime`」的经典模式；回归采样淡出曲线 [0 → 0.35 → 0.13 → 0.006 → 0]，预设切换后能量归零。
- ✅ 单测覆盖：自然完成/跳过/重置的上报语义（completed 区分计轮）、暂停时真实时间流逝不影响剩余、空记录连胜为 0、损坏 JSON 回退等 32 例。

## Round 4 — 视觉批评 → 推翻重做

**截图批评（1280×800，亮/暗双主题）**：

- ❌ **[P1] 主题过渡动画在节流环境下冻结在中间态**：body 背景卡在 rgb(37,40,45)（89% 进度），页面呈「亮底白字」的撕裂状。
- ❌ **[P2] 初始静音图标误用 🔇**（实际声音开启）。

- 删除主题过渡动画，主题切换即时生效。验证：背景精确 rgb(10,14,21)。
- 初始图标改 🔈；声波振幅 0.16→0.19。
- 复审：暗色主题下六卡片通道色微光、底部多通道彩色声波、琥珀色主按钮，构图达标。

## Round 6 — 用户反馈「底噪很大」→ 测量驱动的音频大修

**用户反馈**：声音有很大的底噪。自问「能否自己看到」→ 给引擎加 `masterNode` 输出抽头，
用 ScriptProcessor 抓取真实输出 PCM，量化 RMS/峰值/削波数/逐采样跳变/九段频谱。

**基线测量（修复前）**：
- 静默态 RMS -93dB：引擎底噪干净，排除泄漏；
- 仅雨声：RMS **-10dBFS**、峰值 **+1.1dBFS 已削波**、11.2 万个 >0.1 的采样跳变；
- 仅炉火：峰值 **+3.9dB**、**31Hz–16kHz 频谱全平**（棕噪本应低通 340Hz）→ 锁定「存在未滤波白噪直通」。

**根因**：`triggerVoice` 把整条节点链逐个 connect 到 sink——包括第一个声源本身。
每颗雨滴/每次爆裂/每声鸟叫在正常包络版本之外，还同步播放一份**未滤波、满幅的原始噪声**
（纯振荡器语音则是裸正弦音爆）。事件密度高（雨滴每 35-260ms 一颗），叠加即持续白噪底 + 削波失真。
此前的「能量级」断言只验证了「有信号」，无法发现「信号是错的」。

**修复**：
1. `triggerVoice` 契约重设计：setup 返回 `{ output, sources, extras }`，仅 `output` 接入 sink；五个通道的事件语音全部按新契约改造；
2. 噪声缓冲音频卫生：去直流（棕噪随机游走漂移）+ 60ms 环绕等功率交叉淡化（消除 4 秒循环接缝的咔哒/顿挫）；
3. 主链加 24Hz 高通（截断次声/直流）与 9kHz 柔性低通；压限器放松（-18/4:1 → -14/2.5:1），消除泵感；
4. 电平重平衡：雨嘶声层 0.35→0.22、低通 1800→1500，雨体感层 0.16→0.22；火床 0.5→0.42；风 0.3→0.26（呼哨 0.028→0.018）；溪流 0.3→0.26；夜虫底噪 0.06→0.05。

**复测（修复后）**：
- 雨声：RMS -34.2dB、峰值 -21.6dB、零削波、零跳变、频谱呈中低频倾斜；
- 炉火：RMS -27.9dB、峰值 -15.8dB、频谱低频主导（8kHz 以上 -157dB）；
- 静默态保持 -98.7dB 数字静音。
- 教训：**音频系统的验收必须测波形与频谱，能量「有/无」级断言不够。**

## Round 7 — 获奖级品质升级（Awwwards 标准自检）

**核心动作：让「声屿 = 声音之岛」的隐喻成为产品的署名视觉。**

- **夜海场景引擎**（`src/ui/scene.ts`，替代原 72px 可视化条）：星空闪烁、月亮与海面月径碎光、
  三层海浪（每层绑定一个启用通道的色相与实时能量）、通道粒子系统
  （雨=斜落雨丝、炉火=升腾余烬、夜虫=呼吸流萤、风=横移薄雾、溪流=水线碎光、鸟鸣=掠影）。
  混音状态即风景。静音时整个海面黯淡为 38%。
- **布局重构**：全出血场景 + 悬浮 UI——计时器浮于海面之上，混音台收进底部玻璃坞
  （backdrop-blur + 通道色微光模块），预设收为胶囊按钮（mood 转为 tooltip）。
- **排版**：引入 Space Grotesk（300/500）用于时钟数字（tabular-nums）、拉丁标签、统计数字；
  品牌标志重绘为内联 SVG（月 + 双浪）。
- **动效编排**：分层入场（顶栏→计时器→控制台→卡片 55ms 逐级 stagger，blur+rise）；
  运行中圆环呼吸光晕；阶段切换整环搏动；主按钮缓慢流光。
- **微交互**：卡片指针跟随 3D 倾斜、滑杆通道色填充 + 拖拽音量读数气泡、
  快捷键触发光晕回响（card-flash）、静音联动 dock 减透明度。
- **健壮性**：入场动画「保险丝」——环境节流（后台标签页加载）可能把 CSS 动画冻在中间态
  （实测 IAB 中 rise-in 卡在 running 767ms），2.5s 后 `is-settled` 移除动画强制落位，
  保证任何环境下 UI 终态正确。
- **渲染修复**：海面基底矩形上边缘暴露为直线伪影 → 移除基底、深度由三层波浪填充叠加；
  月径两遍绘制（宽淡+窄亮）增强。
- **主题对比度**：亮色纸面上选中的模式胶囊改为白底琥珀边（原 accent-soft 发白不可读）。
- 性能守则：单画布、DPR ≤1.75、粒子数上限与通道音量挂钩、`prefers-reduced-motion` 下降级为静帧海面。

**八轴自检结论**（详见最终交付说明）：排版（SG 数字 + 中文黑体层级）、留白（全出血场景即空气）、
视觉层级（天空计时器 → 海面坞 → 顶栏）、色彩（墨蓝夜海 + 六通道色相系统）、
动效（入场编排 + 呼吸 + 搏动 + 流光）、微交互（倾斜/读数/闪光/静音联动）、
响应式（1280/768/375 全验证，移动端预设横向滑动）、原创性（混音即风景的署名场景）。
